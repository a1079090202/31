# 修车铺维修台账

本店自用的维修台账：接车建单、状态流转、换件登记、旧件保管、配件库存、月度毛利汇总。
纯本地运行，SQLite 存库，不连任何云端。

## 启动

```bash
npm install        # 第一次
npm run dev        # 开发模式，浏览器打开 http://localhost:5173
```

正式一点跑：

```bash
npm run build
npm start          # 打开 http://localhost:3000
```

数据存在 `data/shop.db`，首次启动若是空库会自动灌入 6 台样单和 10 种配件库存。
想清空重来：`npm run reset`。

## 测试

```bash
npm test
```

覆盖四块：状态跳级拦截、负库存拦截、保管期满提醒、月度毛利汇总。

## 日常用法

1. **接车建单**：记车架号后六位、品牌、故障描述、预估工费、预计完工时间。
2. **状态流转**：待修 → 在修 → 待取件 → 已交车，只能一级一级推进；跳级会被拦下并提示差哪一步。已交车的单内容锁定改不了；未交车的单可作废，但必须留原因和经手人。
3. **换件登记**：来源分「客户自带配件」（零成本、不动库存）和「店里库存领用」（立即扣库存，不够扣整笔拦下，不会扣成负数）。
4. **旧件**：拆下待鉴定的旧件默认进保管区，保管期 14 天，超期未处理进「待处置」提醒（首页和保管区都有提示）。处理去向三种：退还客户、报废、转可用库存（必填质检备注，转可用后库存 +1）。
5. **月度汇总**：按交车月份归集，逐台列出工费、配件成本、毛利（毛利 = 工费 − 库存领用成本），可导出 CSV 拿计算器逐笔核对。

## 技术约定

- SvelteKit + SQLite（better-sqlite3），无重型组件库，原生表单 + 一点 CSS。
- 金额一律按「分」存整数（`INTEGER`），展示层才格式化成元。
- 日期时间一律本地时间字符串 `YYYY-MM-DD HH:mm:ss`。
- 业务不进路由，路由只做取表单、调模块、回错误：

| 模块 | 职责 |
| --- | --- |
| `src/lib/server/stateMachine.js` | 工单状态机：能不能走、差哪步、已交车/已作废锁定 |
| `src/lib/server/inventory.js` | 库存扣减与入库，负库存拦截 |
| `src/lib/server/storage.js` | 旧件 14 天保管期计算、待处置列表 |
| `src/lib/server/orders.js` | 建单、改单、推进、作废 |
| `src/lib/server/parts.js` | 换件登记（三种来源）、旧件处理（三种去向） |
| `src/lib/server/reports.js` | 月度汇总与 CSV |
| `src/lib/server/money.js` / `time.js` | 分↔元、本地时间工具 |
